# SEP11 Freedom Project
by **Cammi Wong**

## Context
I am a student at [HSTAT](https://www.hstat.org/) in the [Software Engineering Program](https://hstatsep.github.io/). The "Freedom Project" for SEP11 is a year-long project all about making something using JavaScript along with a third-party JS tool. I made a game on the topic of choice making for my users to learn from.

For my project, I chose to independently study **gardening, decision making, and kaboom.JS** in order to help me make a **Garden Game**. Many people in life struggle with decision making because they are not exposed to them. It is essential to make choices difficult or easy each time, as it helps choose a path that is well suited for you.

## Content
My blog contains information about my steps of coding to finish my SEP Freedom Project. My blog has the steps I took from an Minimum Viable Product(MVP) to a beyond MVP and helped me organize all the time lines and steps I have taken to go back into.
